texshelf starts LaTeX and Typst projects from templates. Browse them at
[tex.jjsm.science](https://tex.jjsm.science), or from a terminal:

```console
texshelf init article my-paper
typshelf init notes-typst calculus
```

| Repository | Contents |
| --- | --- |
| [texshelf](https://github.com/texshelf/texshelf) | The `texshelf` and `typshelf` commands, written in Rust |
| [registry](https://github.com/texshelf/registry) | One manifest per template version. Add your template here. |
| [templates](https://github.com/texshelf/templates) | Templates the project maintains itself |
| [web](https://github.com/texshelf/web) | The website |
| [brand](https://github.com/texshelf/brand) | Logos and colours |
| [homebrew-tap](https://github.com/texshelf/homebrew-tap) | Homebrew formula, once there is a release |
