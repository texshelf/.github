# Getting help

- How to use the commands: the [documentation](https://docs.jjsm.science/latex/texshelf/)
  and `texshelf --help`.
- A template does not compile on your machine: run `texshelf doctor main.tex`
  first. It lists the TeX packages the document needs and you do not have.
- Something looks like a bug: open an issue in the repository it belongs to.
  [CONTRIBUTING.md](CONTRIBUTING.md) has a table of which one.
- Questions about LaTeX or Typst themselves are better asked at
  [TeX Stack Exchange](https://tex.stackexchange.com) or the
  [Typst forum](https://forum.typst.app), where far more people can answer.
